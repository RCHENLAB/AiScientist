Skill review

              
Skills the lab learned on its own from earlier runs. Each is one run's code turned into a template, with that dataset's format and column names inside it, so no run can plan with it or use it until an admin approves it. Hand-written skills are not listed here; they are always available.

Skill requests

              
Runs that needed code the AI wrote during the run, because no tested tool did the job. Each record holds the request, what kind of data it ran on (never the data), every code attempt with its result and the Critic's verdict, and a summary. Similar requests are grouped, so the most-needed skills stand out. Credentials, server paths and e-mail addresses are removed before a record is written; the request text and the code are dropped after the retention period.

API keys

              
Every API key on this server, saved or for one session only, as its owner sees it (never the key). Pause stops every use of a key at its next model call; the owner is told, and only an administrator can resume it. The spike check pauses a key on its own when its last hour far exceeds its usual use.

Cluster models

        
      

      

        Weight sets the cluster GPU can serve. Pick one in the LLM endpoint box. Switching
        during a session keeps your current card when the new model can run on it (only the model
        reloads, a few minutes); otherwise the card is released and a new GPU job is queued. The
        default is what a new session gets unless it picks another.
